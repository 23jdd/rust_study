# 面向对象编程特性

Rust 并非传统 OOP 语言，但提供了类似的抽象机制。

## Trait Object：抽象共享行为
```rs
// trait object 使用 dyn 关键字
pub trait Draw {
    fn draw(&self);
}

pub struct Screen {
    // 使用 Box<dyn Draw> 存放不同类型（动态分发）
    pub components: Vec<Box<dyn Draw>>,
}

impl Screen {
    pub fn run(&self) {
        for component in self.components.iter() {
            component.draw();
        }
    }
}

// 不同组件实现同一个 trait
pub struct Button { pub width: u32, pub height: u32, pub label: String }
impl Draw for Button { fn draw(&self) { /* 绘制按钮 */ } }

pub struct SelectBox { pub width: u32, pub height: u32, pub options: Vec<String> }
impl Draw for SelectBox { fn draw(&self) { /* 绘制选择框 */ } }

// 使用
let screen = Screen {
    components: vec![
        Box::new(SelectBox { width: 75, height: 10, options: vec![...] }),
        Box::new(Button { width: 50, height: 10, label: String::from("OK") }),
    ],
};
screen.run();
```

## 对比泛型与 trait object
```rs
// 泛型 + trait bound（静态分发）：编译时确定类型，零运行时开销，但每个具体类型生成一份代码
pub struct Screen<T: Draw> { pub components: Vec<T> }  // 只能存同一种类型

// trait object（动态分发）：运行时确定类型，有一点开销，但可以存不同类型
pub struct Screen { pub components: Vec<Box<dyn Draw>> }
```

## 对象安全（Object Safety）
只有**对象安全**的 trait 才能用作 trait object：
- 方法的返回类型不能是 `Self`
- 方法不能有泛型参数

## 实现 OOP 设计模式：状态模式
```rs
// 用 Rust 的方式实现状态模式（用类型系统编码状态）

// 方式一：使用 trait object
pub struct Post {
    state: Option<Box<dyn State>>,
    content: String,
}
trait State { fn request_review(self: Box<Self>) -> Box<dyn State>; }
// ... 为 Draft、PendingReview、Published 实现 State

// 方式二：将状态编码为不同类型（更 Rust 化）
pub struct DraftPost { content: String }
pub struct PendingReviewPost { content: String }
pub struct Post { content: String }

impl DraftPost {
    pub fn add_text(&mut self, text: &str) { self.content.push_str(text); }
    pub fn request_review(self) -> PendingReviewPost {
        PendingReviewPost { content: self.content }
    }
}

impl PendingReviewPost {
    pub fn approve(self) -> Post { Post { content: self.content } }
}

impl Post {
    pub fn content(&self) -> &str { &self.content }
}

// 使用：不同阶段暴露不同方法，编译时保证安全
let mut post = Post::new();            // -> DraftPost
post.add_text("I ate a salad");        // DraftPost 可以加文字
let post = post.request_review();      // -> PendingReviewPost
// post.add_text("...")  // 编译错误！审查阶段不能加文字
let post = post.approve();             // -> Post
assert_eq!("I ate a salad", post.content());
```
