## Cargo

``` bash
cargo run # run cargo package
cargo build # generate exe file
cargo check # check rust code 
cargo add # add dependencies
cargo remove # remove dependencies
cargo tree # dependencies list
cargo install # install rust exe
cargo new # generate new project, --lib point generate lib
cargo clipy 
```
